MuseCat Auto Share — Kurulum Rehberi

OBS Studio + Aitum Vertical ile tek tuşla aldığınız dikey klipleri yayın akışınızı bozmadan YouTube Shorts, Google Drive, Instagram Reels (+ Facebook) ve TikTok'a otomatik aktarın.

1. OBS Studio + Aitum Vertical Klasör Ayarı

  1. OBS Studio'da Aitum Vertical eklentisini kurun ve Backtrack özelliğini etkinleştirin (ör. 60 saniye).
  2. Aitum Vertical ayarlarında kliplerin kaydedildiği klasörü (ör. C:\Users\Kullanici\Videos) not alın.
  3. MuseCat Auto Share → Ayarlar sekmesinde OBS Aitum Vertical Klip Klasörü olarak bu klasörü seçip Ayarları Kaydet butonuna basın.
  4. Üst bardaki rozet yeşil İzleniyor durumuna geçer. Yayın Modu AÇIK iken aldığınız klipler yayında ping/drop oluşturmamak için kuyruğa alınır; yayın bitince tek tıkla hepsini paylaşabilirsiniz.

2. YouTube Shorts & Google Drive Bağlantısı (Tek Dosya ile İkisi Birden)

  1. Google Cloud Console adresine girin ve Yeni Proje oluşturun (MuseCat Auto Share, konum: No organization).
  2. Üst arama çubuğundan sırayla YouTube Data API v3 ve Google Drive API aratıp ikisini de Enable (Etkinleştir) yapın.
  3. Arama çubuğundan OAuth consent screen / Google Auth Platform açın → Get started → Uygulama adı: MuseCat Auto Share, Hedef kitle: External (Harici) seçip oluşturun.
  4. Sol menüden Audience → Test users → + Add users kısmına kendi Gmail adresinizi ekleyip kaydedin.
  5. Sol menüden Clients → + Create client → Tür: Desktop app ("AI-powered agent" kutucuğunu işaretlemeyin) → Create → Download JSON.
  6. MuseCat Auto Share → Hesaplar & API sekmesindeki Google kartından Dosya Seç ile indirdiğiniz JSON dosyasını seçin ve YouTube & Drive Bağlantısını Test Et butonuna basın.
  7. Tarayıcı 2 kez arka arkaya açılır (1. YouTube izni, 2. Google Drive izni). İkisini de onayladığınızda bağlantı kalıcı olarak kaydedilir.
Google Drive Yedekleme: Tüm klipleriniz otomatik olarak Google Drive içinde AutoClipShare_Backups/YYYY-AA-GG klasörüne yedeklenir ve aynı zamanda Instagram Reels için ücretsiz video bağlantısı sağlar.

3. Instagram Reels (+ Facebook Otomatik Paylaşım)

Ön Hazırlık

  1. Instagram uygulamasında Ayarlar → Hesap türü ve araçları → Profesyonel hesaba geç → İçerik Üreticisi yapın (ücretsizdir, mavi tik gerekmez).
  2. Bir Facebook Sayfası oluşturun ve sayfanın Ayarlar → Bağlı Hesaplar → Instagram bölümünden Instagram hesabınızı bağlayın.

Meta Uygulaması & Süresi Dolmayan Token

  1. Meta for Developers → Uygulama Oluştur → Kullanım alanı: Manage messaging & content on Instagram → Uygulama adı: MuseCat Auto Share.
  2. Sol menüden Kullanım durumları → Özelleştir → API setup with Unified login ekranını açın.
  3. 1. Configure your app bölümünde Create new configuration → Create from template butonuna basın.
  4. 2. Generate access tokens bölümünde Add account ile hesabınızı Instagram Tester olarak ekleyin.
  5. instagram.com/accounts/manage_access → Test Kullanıcısı Davetleri sekmesinden daveti Kabul Et yapın.
  6. Meta Developers sayfasını yenileyin (F5) → hesabınızın yanındaki Generate token butonuna basıp çıkan Access Token ve sayısal Instagram ID bilgisini kopyalayın.
  7. MuseCat Auto Share → Hesaplar & API → Instagram Reels kartına yapıştırın (Public URL Modu: gdrive) → Kaydet → Instagram Bağlantısını Test Et.
Facebook'ta Otomatik Paylaşım İpucu: Instagram mobil uygulamasında Ayarlar → Paylaşım ve remiksler → Facebook'ta otomatik paylaş seçeneğini açarsanız, MuseCat Auto Share ile Instagram'a yüklenen her Reels otomatik olarak Facebook sayfanızda da paylaşılır.

4. TikTok (Content Posting API)

  1. TikTok for Developers portalında ücretsiz geliştirici hesabı açın ve Manage apps → Create an app ile MuseCat Auto Share uygulamasını oluşturun.
  2. Uygulama içine Content Posting API ürününü ekleyin (video.upload ve video.publish kapsamları).
  3. Aldığınız Access Token bilgisini MuseCat Auto Share → Hesaplar & API → TikTok kartına yapıştırıp Kaydet deyin.
Önemli Bilgi: TikTok resmi API'si incelemeden (App Review) geçene kadar inbox (Taslaklar) modunda çalışır; videolarınız doğrudan TikTok uygulamanızın Gelen Kutusu / Taslaklar bölümüne düşer ve telefondan tek tıkla yayınlarsınız. Uygulama onayı alındıktan sonra direct (Doğrudan) moduna geçebilirsiniz.
