MuseCat Auto Share — Setup Guide

Automatically queue and publish vertical 9:16 OBS Studio + Aitum Vertical clips to YouTube Shorts, Google Drive, Instagram Reels (+ Facebook), and TikTok without interrupting your live stream.

1. Auto-Watch Folder or Manual Clip Upload

  1. Automatic Folder Watching: Open MuseCat Auto Share → Settings and select any folder where your clips are saved (OBS Studio, Aitum Vertical, NVIDIA ShadowPlay, Medal, etc.), then click Save Settings.
  2. Manual Upload (No OBS/Aitum Required): You can also add any vertical video exported from CapCut, Premiere, or DaVinci Resolve directly using the Add Clip button in the Clip Queue.
  3. Keep Stream-Safe Mode ON while live so clips queue quietly with zero ping/frame drop; click Stream Ended → Share All Queue when your stream finishes.

2. YouTube Shorts & Google Drive (One File for Both)

  1. Open Google Cloud Console and create a new project (e.g., MuseCat Auto Share).
  2. Search and Enable both YouTube Data API v3 and Google Drive API.
  3. Open Google Auth Platform / OAuth consent screen → Get started → choose External and finish setup.
  4. Go to Audience → Test users → + Add users and add your own Gmail address.
  5. Go to Clients → + Create client → select Desktop app (leave "AI-powered agent" unchecked) → Create → Download JSON.
  6. In MuseCat Auto Share → Accounts & API, select your downloaded JSON file and click Test YouTube & Drive Connection.
  7. Your browser will open twice (1st for YouTube, 2nd for Google Drive). Approve both to save persistent tokens.
Free Instagram URL Bridge: Clips backed up to Google Drive are never duplicated and automatically provide the free public video URL required by Instagram's Reels API.

3. Instagram Reels (+ Automatic Facebook Cross-Posting)

Prerequisites

  1. Switch your Instagram account to a free Professional (Creator / Business) account.
  2. Link your Instagram account to a Facebook Page (Page Settings → Linked Accounts → Instagram).

Meta App & Non-Expiring Token

  1. Open Meta for Developers → Create App → select Manage messaging & content on Instagram.
  2. Open Use cases → Customize → API setup with Unified login.
  3. Under 1. Configure your app, click Create new configuration → Create from template.
  4. Under 2. Generate access tokens, click Add account and assign your Instagram account as an Instagram Tester.
  5. Accept the invite at instagram.com/accounts/manage_access → Tester Invites.
  6. Refresh the Meta Developers page (F5) and click Generate token next to your account. Copy the Access Token and numeric Instagram Account ID.
  7. Paste both into MuseCat Auto Share → Accounts & API → Instagram Reels (Public URL Mode: gdrive) → Save → Test Connection.
Facebook Cross-Posting Tip: Enable Share to Facebook automatically in your Instagram mobile app settings so every Reel uploaded by MuseCat Auto Share is automatically posted to your Facebook Page too.

4. TikTok (Content Posting API)

  1. Sign in at TikTok for Developers, create an Organization, and create a new app (Type: Other).
  2. Switch to the Sandbox tab and create a Sandbox.
  3. Upload a 1024×1024 icon (you can use assets/musecat_icon_1024.png), select Platform: Desktop, and add Login Kit + Content Posting API.
  4. Set Login Kit Redirect URI to http://127.0.0.1:8765/callback, add your TikTok account under Target Users, and click Apply changes.
  5. Copy your Sandbox Client Key and Client Secret into MuseCat Auto Share → Accounts & API → TikTok and click Sign in with TikTok.
Note: Unaudited/Sandbox TikTok apps post to inbox (Drafts) so clips arrive directly in your TikTok app Inbox ready for 1-tap publishing. After passing TikTok's free Production App Review, you can switch to direct mode.

5. X (Twitter) — Free Video Posting (No Review Wait)

  1. Open X Developer Portal and sign up for the Free Tier (500 posts/month free).
  2. Inside your app, open User authentication settings → Set up and set App permissions to Read and write.
  3. Go to Keys and tokens and copy your 4 keys: API Key, API Secret, Access Token, and Access Token Secret.
  4. Paste them into MuseCat Auto Share → Accounts & API → X (Twitter), click Save, and click Test Connection.
